Capabilities

不是生成器拼盘，
是一条能落地的内容生产线。

从商品事实到成功版本，每一步都可追溯、可重试、可复用；AI 只建议，付费执行前必须由人预览确认。

聊

商品长期聊天

截图、链接与手动描述边聊边整理，沉淀名称、参数、材质、卖点与证据，不因会话结束而丢失上下文。

画

项目无限画布

商品输入、图片输入、提示词、生图、改图、合成、视频与输出八类节点，连线按媒体类型校验。

影

视频工作台

AI 生成脚本与分镜，分镜直接成为画布节点；全部镜头成功后由服务端 ffmpeg 拼接成片。

模

模型中心

目录发现与执行能力分离，文本、视觉、图片、视频渠道分别配置；新发现模型默认不启用。

任

可靠任务执行

持久化任务、同编号幂等、取消、失败重试与供应商状态轮询；不自动重提、不自动换模型。

权

权限与审计

管理员、运营、查看者三角色逐接口鉴权；会话令牌不入 localStorage，渠道密钥加密存储。

Workflow

主流程

商品资料独立沉淀，项目按任务组织；预览范围后再开始，下游引用具体成功版本，而不是「最新一次」。

商品长期聊天事实、截图证据与建议持续沉淀
独立创作素材资料图、创作素材、结果与蒙版分开
项目无限画布节点连接商品、提示词与生成能力
预览并开始先看范围与参数，再创建付费任务
选择成功版本下游手选具体版本，不自动取最新
再开始打包、导出或继续下一轮创作
Architecture

全栈自建，
关键边界留在服务端。

前端React 19、Vite 8、@xyflow/react 12
后端Node.js 24、原生 HTTP、自动路由发现
数据PostgreSQL 持久化业务数据与任务队列
对象存储MinIO 私有桶，浏览器不持有长期密钥
模型OpenAI 兼容、Anthropic、DeepSeek、OMYAI、MiniMax H3
媒体ffmpeg 拼接、图片元数据校验、媒体签名
测试Node test runner、PostgreSQL 集成测试、Playwright
浏览器 · React 工作区 / 画布 / 素材
↓ 同源 API + HttpOnly 会话 + CSRF
Node API · 鉴权 / 任务 / 聚合 / 媒体签名
↓ 服务端持有连接与密钥
PostgreSQL · 聊天 / 项目 / 任务 / 审计
MinIO · 私有素材与导出对象
模型渠道 · 文本 / 视觉 / 图片 / 视频
ffmpeg · 视频镜头拼接与成片
项目边界：视频 H3 目前完成协议 fixture 验证，未做真实付费调用验收；截图识别需同时配置文本与视觉渠道；在线体验环境使用独立数据库、独立模型额度与公共可信 TLS。
